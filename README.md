# AI-Resume-Portfolio-Generator
AI Resume &amp; Portfolio Generator using HTML, CSS, JS, Firebase

A modern web application that generates a professional resume and automatically converts it into a personal portfolio website using structured data and AI simulation.

## 📌 Project Overview

This project allows users to input their details such as education, skills, projects, and experience.
It then generates:

* 📄 A professional ATS-friendly resume
* 🌐 A dynamic portfolio website (opens in a new tab)

The system uses **AI simulation logic** to generate content without using any external API.

## ✨ Features

* 🧾 Resume Input Form (User-friendly UI)
* 🤖 AI Content Generation (Simulation)
* 🎯 Role-Based Customization
* 📄 ATS-Friendly Resume Formatting
* 🌐 Portfolio Website Generation
* 🎨 Glassmorphism UI Design
* 📊 ATS Score Display
* 📥 PDF Download Option
* 🔥 Firebase Database Integration (Data Storage)
* 🔗 Live Portfolio Preview (New Tab)

## 🛠️ Tech Stack

* HTML5
* CSS3 (Glassmorphism UI)
* JavaScript (Vanilla JS)
* Firebase (Firestore Database)

## ⚙️ How It Works

1. User registers/logs in
2. Fills the resume form
3. Selects job role & experience
4. AI generates content (objective, skills, etc.)
5. Resume is created in structured format
6. Portfolio is generated from same data
7. Portfolio opens in a new tab
8. Data is saved in Firebase


## 🔥 Key Highlights

* No backend required (Frontend + Firebase only)
* AI simulation without APIs
* Clean and professional UI
* Resume & Portfolio consistency
* Real-time data storage
